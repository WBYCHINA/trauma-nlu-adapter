# Step3 部位识别训练数据生成提示词

标签体系严格按 PLAN.md「Step 3 — 受伤部位」定义，共 8 类。

---

请生成 1900 条中文训练数据，用于微调小语言模型识别伤情所在的身体部位。输入是一条伤情描述，输出是部位标签，只能从下面 8 个里选：

1. 头部：头顶、额头、脸、眼、鼻、口、耳、下巴
2. 颈部：脖子、喉咙、颈椎
3. 躯干：胸口、肋骨、肚子、腰、后背、脊柱、屁股（胸、腹、腰、背统一归躯干）
4. 手臂：肩、上臂、胳膊、肘、前臂、手腕
5. 手部：手掌、手背、手指、虎口
6. 腿部：大腿、小腿、腿、膝盖、腘窝、脚踝
7. 足部：脚背、脚底、脚趾、脚跟
8. 多部位：同一描述里明确提到两处以上不同区域（如头和腿同时受伤），或出现"浑身""全身"

数量分配：前 7 类各 250 条，多部位 150 条。

生成要求：
- input 是口语化自然语言，3-40 字，可含情绪词（哎哟、疼死我了）
- 30% 样本以"我"开头
- 左右方位词（左手/右腿）可自由出现在 input 里，输出仍用大类、不区分左右
- 20% 样本结尾带皮肤状态后缀（"皮肤粘膜有破损"或"皮肤粘膜完整无损"），模拟上游流水线传来的补全文本，输出不受后缀影响
- 每个部位覆盖不同伤情类型：割伤、烫伤、骨折、撞伤、咬伤、扭伤、擦伤等，不要让某类伤情只绑定一个部位
- input 里不要出现标签词本身（不要写"躯干""多部位"这几个字），但身体部位词必须出现
- 边界判定：手腕归手臂、手背手掌归手部；脚踝归腿部、脚背脚趾归足部；腰和后背都归躯干
- JSON 数组格式：{"input": "哎哟我脚背被开水烫了 皮肤粘膜有破损", "output": "足部"}
- 直接输出 JSON 数组，不要解释文字
