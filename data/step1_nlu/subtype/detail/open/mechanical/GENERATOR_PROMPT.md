# 开放式机械性损伤训练数据生成提示词

请生成一份 JSON 格式的训练数据，用于微调一个中文小语言模型做伤情细分类型分类。

## 任务定义

输入是一句普通人对伤情的自然语言描述（可能是报案电话、急救呼救、向医生陈述伤情），输出是对应的细分类型标签（11 选 1）。

## 11 个细分类型及判定标准

所有伤情的共同前提：**皮肤或粘膜有破损**（这是开放式损伤的定义）。在下面的每个类型中，描述里必须能体现皮肤破损信号（破皮、流血、伤口、撕裂、露肉、可见伤口等），不要生成"皮肤完好"的样本。

1. **切割伤**：锐器（刀、玻璃、金属薄片）划开皮肤形成线形伤口。特征：边缘整齐、出血明显。常见表达：被菜刀切了、手让玻璃划了道口子、手臂被刀片割破。
2. **刺伤**：尖锐物（钉子、针、刀尖、竹签）扎入形成深而小的伤口。特征：伤口小但深、易伤及深部组织。常见表达：踩到钉子扎进脚里、手被螺丝刀戳了、针扎进肉里拔不出来。
3. **挫裂伤**：钝物撞击导致皮肤撕裂，伤口边缘不规则。特征：受力处皮肤裂开、伴瘀青。常见表达：头撞桌角裂了道口子、腿被锤子砸破皮了、脸磕地上磕开口子。
4. **撕裂伤**：外力拉扯导致皮肤和组织撕裂。特征：伤口不规则、组织撕开。常见表达：手被机器卷进去撕开了、胳膊被狗咬得撕了一块、头发被卷进机器把头皮撕了。
5. **撕脱伤**：外力将皮肤及皮下组织从深筋膜上撕脱。特征：大面积皮肤脱套、创面大。常见表达：手臂被车轮碾过去皮都脱了、腿让机器绞掉了一大片皮、手被皮带卷进去脱了一层皮。
6. **开放性骨折**：骨折断端刺破皮肤与外界相通。特征：骨断+皮肤破+骨头外露。必须同时有骨折信号（骨折、断了、折了、骨头）和皮肤破损信号（戳破、顶破、露出来、破皮、流血）。常见表达：腿骨折骨头戳出来了、手臂断了骨头露在外面、小腿折了皮破了能看见骨头。
7. **爆炸碎片伤**：爆炸产生的碎片高速击中人体造成多发伤口。特征：多发伤+碎片嵌入+爆炸场景。常见表达：被爆竹炸了满身伤口、烟花爆炸碎片扎进胳膊、爆炸飞溅物打在腿上好几个口子。
8. **火器伤**：枪弹或弹片造成的伤口。特征：有入口或贯通伤、组织损伤重。常见表达：被枪打中胳膊、弹片打穿了大腿、气枪子弹打进手里了。
9. **挤压破裂**：重物挤压导致皮肤及深部组织破裂。特征：大面积碾压+组织破碎。常见表达：脚被混凝土块砸扁了皮都裂开、手让液压机压破了、腿被卡车碾过去都碎了。
10. **抓咬伤**：动物或人抓咬形成的皮肤破损。特征：齿痕、抓痕、不规则伤口。常见表达：被狗咬破手了、猫抓了脸好几道血印、让老鼠咬了一口见血了。
11. **擦伤**：粗糙物摩擦表皮浅层破损。特征：浅表、渗血、创面不深。常见表达：膝盖蹭破皮了、胳膊在地上蹭了一片、手让砂纸磨破了。

## 数据格式

输出 JSON 数组，每条样本两个字段：

```json
[
  {"input": "卧槽我刚才在厨房手被菜刀切了一道口子吓死我了", "output": "切割伤"},
  {"input": "脚踩到生锈的钉子扎进去好深", "output": "刺伤"}
]
```

字段说明：
- `input`：普通人的自然语言表达。允许包含脏话、感叹词、求助语、情绪化表达、时间地点。不要清理，保留原汁原味。
- `output`：只写上面 11 个类型之一的中文名，不加任何其他文字。

## 生成要求

1. **每个类型生成 200 条**，总计 2200 条。类型之间严格均衡。
2. **表达要多样化**，覆盖以下维度：
   - 口语化程度：从"患者男性 28 岁左前臂刀切割伤"到"卧槽手让刀切了一道口子好多血"
   - 伤情位置：手、胳膊、腿、脚、头、脸、躯干、脖子都要覆盖
   - 场景：家庭、工地、车祸、打架、户外、厨房、工厂、农场、学校
   - 严重程度：从"蹭破点皮"到"骨头都露出来了"
   - 表达风格：报案电话口吻、和医生讲述、急救呼救、第一人称、第三人称
   - 情绪：冷静陈述、惊慌、愤怒、麻木、害怕
   - 长度：从 5 字到 50 字
3. **每个类型内部要覆盖典型和边缘表达**。例如"切割伤"既要有"被菜刀切了"，也要有"被易拉罐盖划破了手""玻璃碴子划了一下""让纸张割了手指"这种边缘情况。
4. **不要给 input 加任何前缀或标签**，不要出现"伤情："、"描述："、"患者说："等开头。直接就是一句话。
5. **同一种伤情可以有多种说法**，但同一条 input 必须只对应一个 output。
6. **边界样本很重要**：
   - "开放性骨折"必须同时有骨折信号和皮肤破损信号，二者缺一不可。不要生成"骨折"但不提破皮的样本。
   - "撕脱伤"和"撕裂伤"边界模糊时，按损伤面积和深度判定——大面积脱套是撕脱伤，局部撕裂是撕裂伤。
   - "挫裂伤"和"擦伤"边界模糊时，按深度判定——有裂口出血多是挫裂伤，只有表皮擦破是擦伤。
   - "爆炸碎片伤"必须有爆炸场景信号（爆炸、爆竹、烟花、炸弹、爆裂），否则归切割伤或刺伤。
7. **避免标签泄漏**：input 里不要直接出现"切割伤""刺伤"这些类型名作为字面词。
8. **数据要干净**：不要生成重复样本、空 input、output 不在 11 类里的样本。
9. **皮肤破损信号要有但不一定明显**：有些样本明确说"流血了""破皮了"，有些只通过伤情本身隐含（"被菜刀切了"自然意味着破皮）。两种都要。

## 反面示例（不要这样生成）

```json
{"input": "切割伤：患者手被刀切了", "output": "切割伤"}   // 错：标签泄漏+前缀
{"input": "患者手被刀切了，流血不止，皮肤粘膜有破损", "output": "切割伤"}  // 错：过于标准化，像训练集而不是真实报案
{"input": "骨折了", "output": "开放性骨折"}  // 错：没有皮肤破损信号，不能判为开放性
{"input": "被狗咬了", "output": "抓咬伤"}  // 错：没说破皮，可能只是瘀伤
{"input": "被爆竹炸了一下", "output": "爆炸碎片伤"}  // 错：没说有伤口，可能只是吓了一跳
```

## 输出

直接输出 JSON 数组，不要加任何解释文字、markdown 代码块标记或前言。
