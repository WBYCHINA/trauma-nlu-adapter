# Step2b 机械组细分增广提示词（摔落机制）

目的：现有细分数据里摔落场景几乎全是表皮伤（蹭破皮→擦伤），模型学到的规律是"摔=擦伤"，无法理解高处摔落+剧痛会指向骨折。本批数据教会模型从摔落机制推断伤情类型。

---

请生成 650 条中文训练数据，用于微调小语言模型判断开放性机械损伤的具体类型。所有输入共同前提：皮肤有破损。场景重点：摔落、坠落、跌倒造成的伤。

11 个类型：切割伤、刺伤、挫裂伤、撕裂伤、撕脱伤、开放性骨折、爆炸碎片伤、火器伤、挤压破裂、抓咬伤、擦伤。

数量分配：
- 开放性骨折 200 条：全部为摔落/坠落/高处摔/摔倒场景。其中 100 条明确提到骨折迹象（变形、骨头外露、戳破皮肤、骨头戳出来）；另外 100 条不出现"骨折/断了/折了"等词，只写摔落+皮肤破损+剧烈疼痛+腿变形/动不了/站不起来，让模型从机制推断
- 挫裂伤 150 条：摔落/磕到/撞到导致皮肤磕破、撞破、肿起、伤口边缘不齐
- 擦伤 120 条：摔倒蹭破皮、擦破、渗血、面积大但浅
- 撕脱伤 100 条：摔倒或卷入机器导致皮掀起来、脱套、掉一块皮
- 撕裂伤 80 条：摔到玻璃/铁皮上伤口豁开、边缘不齐

生成要求：
- input 是口语化自然语言，可带情绪词（哎哟、疼死我了）
- 40% 样本以"我"开头（如"我从梯子上摔下来"），让模型适应代词开头
- 30% 样本不出现任何类型名
- 场景覆盖：楼梯、梯子、脚手架、山坡、电动车、自行车、浴室滑倒、球场
- 部位覆盖：腿、膝盖、胳膊、肘、肩、头、脸、背、手腕
- output 只能是 11 个类型名之一
- JSON 数组格式：{"input": "从架子上摔下来膝盖肿得动不了还渗血", "output": "开放性骨折"}
- 直接输出 JSON 数组，不要解释文字
