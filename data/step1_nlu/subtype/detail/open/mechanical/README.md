## AI 生成 Prompt（复制给另一个 AI）

```
你是急救医学 NLU 数据标注专家。请生成「开放式机械性损伤细分类型」的训练数据。

### 上下文
- Step1（受伤大类型）判定：开放式 → 皮肤/粘膜有破损、有流血
- Step2a（损伤组别）判定：机械性损伤 → 外力物理作用导致的损伤

### 11 个细分类型的定义与边界

| 类型 | 核心特征 | 典型关键词 | 边界裁决 |
|------|---------|-----------|---------|
| 切割伤 | 锐利工具切/割/砍，线性伤口 | 菜刀/剪刀/刀片/美工刀/玻璃/罐头盖 + 切/割/划/砍 | 铁片割断=切割；铁片刮裂=撕裂 |
| 刺伤 | 尖锐物穿刺，点状伤口 | 钉子/竹签/针/锥/叉 + 扎/刺/戳/穿 | 爆炸碎片扎=爆炸碎片伤；动物牙扎=抓咬伤 |
| 挫裂伤 | 钝器撞击致皮肤裂伤 | 撞/磕/砸/碰/挫 + 破/裂/流血 | 锐利工具切=切割；钝器撞破=挫裂 |
| 撕裂伤 | 钝力拉扯致皮肤片状裂开 | 撕裂/扯开/撕/扯裂/拉开/刮裂 | 动物咬后撕开=抓咬伤；铁丝刮扯=撕裂 |
| 撕脱伤 | 大块皮肤/组织整片撕脱翻起 | 撕脱/脱套/剥脱/整块撕掉/卷掉了皮 | 动物咬挣脱=抓咬伤；机器卷掉整块皮=撕脱 |
| 开放性骨折 | 骨折断端穿透皮肤 | 骨折+流血/骨头戳破/骨头露/骨头穿出 | 只要同时有「骨折」+「皮肤破/流血/骨头戳」就归这类 |
| 爆炸碎片伤 | 爆炸冲击波+飞散碎片致伤 | 烟花/爆竹/鞭炮/爆炸/炸伤/碎片/弹片/铁片/锅炉 | 爆炸因果优先：鞭炮爆炸碎片扎=爆炸碎片伤，不是刺伤 |
| 火器伤 | 枪弹/子弹造成的穿透伤 | 中弹/枪伤/子弹/枪弹/霰弹枪/子弹孔 | 仅限枪支弹药，烟花=爆炸碎片 |
| 挤压破裂 | 挤压/碾压致皮肤软组织破裂 | 挤压/压碎/压破/压爆/被压/被挤/碾压 | 门夹、机器碾压、重物挤压都归这类 |
| 抓咬伤 | 动物牙齿/爪子造成的损伤 | 被狗咬/被猫抓/被蛇咬/被熊咬/被野猪拱/被鳄鱼咬 | 有动物+咬/抓/挠 的因果就归这类，不管伤口形态 |
| 擦伤 | 摩擦/刮蹭致表皮剥脱（浅） | 擦/蹭/搓破/擦破/蹭破/刮破/擦伤 | 只有摩擦蹭破表皮，没有深伤口 |

### 身体部位参考（随机使用）
手指、手掌、手背、手腕、胳膊、手臂、肘部、肩膀、
脚趾、脚掌、脚背、脚踝、小腿、膝盖、大腿、腿、
头部、额头、脸、脸颊、下巴、耳朵、
脖子、胸口、胸部、后背、腰、肚子、腹部、指甲

### 要求
1. **口语化**：普通人报案会说的话，不要医学术语
2. **多样化**：每个类型 200 条，覆盖不同部位、不同工具、不同表述（主动/被动/省略主语）
3. **边界测试**：故意生成模糊描述来测试边界
   - "被铁片划了一道口子" → 切割伤
   - "被铁片刮裂了" → 撕裂伤
   - "被树枝刮破了皮" → 擦伤
   - "被树枝撕裂了一道口子" → 撕裂伤
4. **骨折类必须有皮肤破损信号**：开放性骨折 = 骨折 + 流血/破皮/骨头戳出，不能只有"骨折"
5. **抓咬伤必须有动物**：不能只写"被咬了"，要写什么动物
6. **去重**：不要重复句式
7. **数量**：11 类型 × 200 条 = 2200 条左右
8. **格式**：严格 JSON 数组，每条 {"input": "中文描述", "output": "类型名"}

### 输出示例
```json
