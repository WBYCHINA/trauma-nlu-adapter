# Step2a 组别分类增广提示词（第一人称口语短句）

目的：现有组别训练数据多为完整描述句，模型对"我骨折了"这类第一人称口语短句容易误判成"病理自发性破溃"。本批数据补齐口语短句形态。

---

请生成 300 条中文训练数据，用于微调小语言模型判断开放性损伤的成因组别。输入是普通人报案时的口语短句，输出是 7 个组别之一：

1. 机械性损伤：外力造成（割、刺、摔、撞、夹、咬、爆炸碎片），皮肤有破损
2. 热力损伤：烧烫伤、烫伤后破溃起泡
3. 电能损伤：触电、电击造成的伤口或焦痂
4. 化学腐蚀：酸碱或化学品造成的皮肤腐蚀溃烂
5. 辐射损伤：放射性或强紫外线造成的皮肤破溃
6. 生物毒素-感染：毒蛇毒虫咬蜇、动物咬伤破皮、伤口感染溃脓
7. 病理自发性破溃：没有外伤，皮肤或黏膜自己溃烂破溃（压疮、溃疡、坏疽）

数量分配：
- 机械性损伤 150 条：骨折戳破皮肤、割破、划伤、夹伤、摔破、撞破、擦破皮
- 热力损伤 60 条：开水烫、火烧、油溅、烤火烫伤
- 病理自发性破溃 30 条：皮肤莫名溃烂、长期卧床压破、老烂腿、糖尿病足溃破（要点明"没有磕碰""自己烂的"）
- 电能损伤 20 条：触电、被电打了个口子
- 化学腐蚀 20 条：被酸烧了、化学品溅到皮肤烂了
- 生物毒素-感染 20 条：被蛇咬、被狗咬破、伤口化脓

生成要求：
- input 5-20 字，60% 以"我"开头（如"我骨折了""我被门夹了"）
- 30% 的 input 结尾带"皮肤粘膜有破损"后缀，模拟流水线传来的补全文本
- input 里不要出现组别名（机械、热力、病理等词），但伤情本身要清楚
- 病理类必须能和外伤区分开：有明确外伤原因的不能标成病理
- JSON 数组格式：{"input": "我骨折了 皮肤粘膜有破损", "output": "机械性损伤"}
- 直接输出 JSON 数组，不要解释文字
